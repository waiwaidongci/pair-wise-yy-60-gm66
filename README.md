# pair-wise-yy-60 碳减排项目监测证据核验与签发准备平台

按监测周期完成活动数据、排放因子、证据来源、异常波动和计算链核验。支持抽样任务、版本化数据修订、发现项闭环和签发前完整性检查。

## 带基线版本的核验流程

- **修订留痕**：每次修订生成新基线版本，永久保留原始值、排放因子、证据编号与修订原因，并按当时数据生成不可变计算快照（`Revision.snapshot`），历史版本不被覆盖。
- **字段级签署**：核验员只能签自己负责的字段（活动数据/排放因子/来源证据/时间范围），字段被修订后其签署自动失效；全部字段签署后，仅复核人可完成记录。
- **草稿与并发合并**：修订先生成携带基线版本的草稿。基于旧基线提交时，未被他人改过的字段自动合并，双方都改过的字段进入冲突裁决，裁决前阻塞签发。
- **签发失效**：签发结果与门禁结论绑定数据指纹（epoch）。监测期数据一变化，旧签发结果立即失效、就绪度实时重算，门禁需按当前指纹重新确认。
- **失败重试**：提交失败的草稿保留在草稿箱中，可恢复重试；重试与重复提交均幂等，不会生成新版本。

核心逻辑在 `lib/engine.ts`（纯函数，可单测），状态接入在 `lib/store.ts`。

## 技术栈

Next.js App Router、MUI、Zustand、TanStack Query、ky、Zod、TypeScript。

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62060`。`/api/evidence` 提供分页场景所需的本地 REST 数据接口。

```bash
npm run build        # 生产构建
npm run test:engine  # 引擎与存储行为校验（合并/冲突/签署/签发失效/重试幂等）
```
